profiles User Profiles

ColumnTypeDefaultNotes
id PKuuidauth.uid()Links to auth.users
display_nametext—Full name shown on profile
handletext—Unique @username
biotext—Profile bio text
avatartext—Avatar image URL
subscription_priceinteger—CAD cents/month for fans
is_premiumbooleanfalsePremium status flag
premium_untiltimestamptz—Premium expiry date
conversation_themetext—JSON: {bubbleColor, bgTint}
created_attimestamptznow()Account creation time

🔒 RLS Policy

SELECT: Public — anyone can view profiles

INSERT/UPDATE: Owner only — users can only edit their own profile

posts Feed Posts

ColumnTypeDefaultNotes
id PKuuidgen_random_uuid()Unique post ID
user_id FKuuid—→ profiles.id
contenttext—Post text content
image_urltext—Camera photo URL
video_urltext—Camera video URL
font_styletext—Font class name
font_colortext—Hex color code
locationtext—Geolocation string
is_lockedbooleanfalsePaywall enabled
priceinteger—CAD cents to unlock
likes_countinteger0Cached like count
created_attimestamptznow()Post time

🔒 RLS Policy

SELECT: Public — anyone can view public posts

INSERT/UPDATE/DELETE: Owner only

messages Direct Messages

ColumnTypeDefaultNotes
id PKuuidgen_random_uuid()Message ID
sender_id FKuuid—→ profiles.id
receiver_id FKuuid—→ profiles.id
contenttext—Message text
image_urltext—Camera media URL
is_readbooleanfalseRead receipt
created_attimestamptznow()Sent time

🔒 RLS Policy

SELECT: Participants only — sender or receiver can view

INSERT: Authenticated users — can send to anyone

UPDATE/DELETE: Sender only — can only edit/delete own messages

connections Follows / Connects

ColumnTypeDefaultNotes
id PKuuidgen_random_uuid()Connection ID
follower_id FKuuid—→ profiles.id
following_id FKuuid—→ profiles.id
created_attimestamptznow()Connection time

🔒 RLS Policy

SELECT: Public — connection counts are public

INSERT/DELETE: Authenticated — users manage own connections

notifications User Notifications

ColumnTypeDefaultNotes
id PKuuidgen_random_uuid()Notification ID
user_id FKuuid—→ profiles.id (recipient)
typetext—like, comment, follow, message, mention
actor_id FKuuid—→ profiles.id (who triggered)
reference_iduuid—Post/message ID reference
messagetext—Human-readable text
is_readbooleanfalseRead status
created_attimestamptznow()Notification time

🔒 RLS Policy

SELECT: Owner only — users see only their own notifications

INSERT: Authenticated — anyone can trigger notifications
